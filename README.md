# ⚖️ منظومة بيت القانون | ERP المحامي المصري الشامل

منظومة سحابية متكاملة لإدارة مكاتب وشركات المحاماة، مصممة بهندسة تطبيقات متكاملة شبيهة بنظام **Odoo** (All-in-One Legal ERP) ومخصصة للواقع القضائي والإجرائي المصري.

---

## 🌟 المزايا الرئيسية (Apps Ecosystem)

1. **رول الجلسات والمحاكم**: تصنيف القضايا، المواعيد الإجرائية التلقائية طبقاً لقانون المرافعات، وطباعة كشوف المحكمة اليومية فورياً.
2. **إدارة القضايا والملفات**: ملف رقمي شامل لكل قضية (مدني، جنائي، مجلس دولة، أسرة، جنح، شيكات، عمال، تجاري).
3. **سجل الموكلين والتوكيلات**: قاعدة بيانات الموكلين، تواريخ سريان التوكيلات، والإخطارات التلقائية.
4. **المستشار الذكي (زيزو AI)**: صياغة مذكرات النقض، عرائض الدعاوى، والإنذارات الرسمية بضغطة زر.
5. **نماذج العقود والمذكرات**: مكتبة من 30+ صيغة قانونية معتمدة قابلة للتعبئة الآلية والطباعة.
6. **حساب المواعيد والطعون**: حساب ذكي للمدد الإجرائية (استئناف 40 يوماً، نقض 60 يوماً، تجديد حبس، إعلان) مع استبعاد أيام العطل الرسمية.
7. **الخزينة والماليات**: الفواتير، الأتعاب المقبوضة، المصروفات القضائية، وحسابات الشركاء والنسب.
8. **المواريث والتركات**: حاسبة إلكترونية لتوزيع الميراث الشرعي طبقاً لأحكام الشريعة والقانون المصري.
9. **الماسح الضوئي (OCR)**: مسح المستندات وتفريغ النصوص واستخراج بيانات الأحكام.
10. **دليل المحاكم والنيابات**: أرقام وعناوين واختصاصات المحاكم والنيابات والشهر العقاري على مستوى الجمهورية.
11. **المكتبة التشريعية**: نصوص القوانين المصرية وأحدث أحكام محكمة النقض.
12. **التقارير والمؤشرات**: لوحات بيانية تنفيذية لأداء المكتب، ونسب الإنجاز، والأرباح.

## 🚀 التشغيل المحلي (Local Development)

```bash

source .venv/bin/activate

# تثبيت الاعتماديات
pip install -r requirements.txt
```

## ☁️ النشر السحابي الدائم 24/7 (Cloud Deployment)

لتشغيل النظام بشكل دائم على الإنترنت بدون الحاجة لترك اللابتوب مفتوحاً:

### الطريقة الأولى: النشر بضغطة زر على Render.com (مجاني)
1. قم برفع المشروع على حسابك في GitHub.
2. اذهب إلى [Render.com](https://render.com) وسجل حساباً مجانياً.
3. اضغط **New +** ثم اختر **Blueprint**.
4. اربط مستودع GitHub؛ سيقوم Render بقراءة ملف `render.yaml` وبناء النظام تلقائياً خلال دقائق.
5. ستحصل على رابط دائم مثل `https://bayt-alqanoon.onrender.com` يعمل على مدار الساعة.

### الطريقة الثانية: النشر عبر Railway.app
1. اذهب إلى [Railway.app](https://railway.app).
2. اختر **New Project** -> **Deploy from GitHub repo**.
3. سيتعرف Railway تلقائياً على ملف `railway.json` و `Dockerfile` ويعطيك رابطاً سريعاً ومستقراً 24/7.

## مساعد زيزو — الربط الفعلي

- المسار الجديد: `POST /api/ai/zizo-advisor`، مع `query` و`history` و`case_id` الاختياري و`mode` (`chat` أو `draft`) و`research`.
- اضبط `OPENAI_API_KEY` في Vercel → Project Settings → Environment Variables → Production، مع تفعيل فوترة API. لا تضع المفتاح في الواجهة أو Git. النشر التالي يستخدم المتغير.
- النموذج الافتراضي `gpt-6-astra`؛ يمكن تغييره بمتغير `ZIZO_MODEL` إلى نموذج يدعمه حسابك وResponses API والبحث. يمكن تعطيل البحث بـ`ZIZO_WEB_SEARCH=false`.
- `GET /api/ai/status` يوضح وجود الإعداد فقط، ولا يدّعي اتصالاً ناجحاً قبل تنفيذ طلب فعلي. تُعرض أخطاء الصلاحيات والرصيد والمهلة برسائل واضحة.
- الدستور كامل بنسخة أبريل 2019 في `/static/constitution.html` وفي ملف JSON يحوي الديباجة والمواد 1–254 والمواد المكررة الثلاث (257 مدخلاً). المصدر: PDF مجلس النواب المنشور بموقع الرئاسة، 114 صفحة. بيانات المصدر وبصمته موجودة داخل JSON. النص المستخرج يحتاج مقابلة صورة الصفحة عند الاقتباس الحرفي. الحواشي منفصلة عن النص الحالي.
- إعادة استخراج الدستور: نزّل PDF الرسمي إلى `static/knowledge/egypt-constitution-2019.pdf` وشغّل `scripts/build_constitution.py` باستخدام Python يحتوي على `pypdf` (اعتمادية بناء فقط).
- المساعد لا يحذف ولا يغيّر بيانات المكتب. يرسل السؤال وسياق القضية المختارة فقط (دون قاعدة المكتب كاملة)، ويستخدم `store=false` في Responses. هذا لا يعني ضمان انعدام الاحتفاظ لدى المزود؛ راجع سياسة بيانات حسابك. سجل الحوار في `sessionStorage` للتبويب الحالي بمعرّف منفصل لكل جلسة مكتب.
- وضع الضيف يتيح الإرشاد والدستور؛ الاستدعاءات المدفوعة تتطلب حساب مكتب. `ZIZO_ALLOW_DEMO_AI=true` يتيح النموذج للضيف صراحةً عند الحاجة.
- الحسابات والبيانات محفوظة في قاعدة Neon مستقلة عبر `DATABASE_URL` السري. الجلسات HttpOnly/Secure/SameSite وليست مفاتيح في localStorage؛ الموجود في المتصفح مجرد علامة `cookie_session`. كلمات المرور PBKDF2-SHA256 (600,000 دورة) بملح منفصل، والتسجيل يتطلب 10–128 حرفاً وبريداً وهاتفاً فريدين. تسجيل الخروج يلغي الجلسة في القاعدة.
- التهيئة تنشئ مخطط `legal_private` في القاعدة الجديدة فقط من `security/schema.sql`. بيانات كل مكتب مقيدة بمعرف الجلسة وشرط SQL ومعيار RLS، مع إصدار للتحديث يرفض تعارض الكتابة بدلاً من فقد البيانات. صلاحيات إدارة الاشتراك من علم `is_admin` المحفوظ في الخادم فقط؛ لا توجد حسابات إدارة جاهزة أو كلمات مرور افتراضية. لا تمنح أي مستخدم هذه الصلاحية إلا بعد التحقق اليدوي من هويته.
- وضع الضيف ببيانات مصطنعة للقراءة فقط. حسابات النسخة القديمة التي كانت في ذاكرة الخادم لا تُرحّل تلقائياً؛ احتفظ بتصدير بياناتها قبل تغيير النشر إن كانت لا تزال متاحة.
- استدعاءات النموذج محدودة في القاعدة: 10/دقيقة و50/يوم للمكتب و200/يوم للمشروع، ويمكن تقليلها بمتغيري `ZIZO_DAILY_OFFICE_LIMIT` و`ZIZO_DAILY_GLOBAL_LIMIT`. هذه حدود عدد طلبات وليست سقف تكلفة بالدولار؛ اضبط فوترة المزود أيضاً.
- الحماية تشمل منع مصادر المتصفح الأخرى، إغلاق أدوات تمديد التجربة العامة، والتحقق من جلسة المكتب في القراءة والكتابة، وعدم تخزين أسرار في Git. سياسة CSP لا تزال تسمح inline/eval بسبب الواجهة القديمة؛ ليست هذه شهادة اختبار اختراق شامل. OCR والحاسبات والمكتبة القانونية القديمة تحتاج مراجعة مستقلة ولا تعتمد عليها كمصدر قانوني محدث.
- اختبارات المساعد: `PYTHONPYCACHEPREFIX=/tmp/zizo-pycache .venv/bin/python -m unittest discover -s tests -v`.

توثيق المزود: https://developers.openai.com/api/docs/guides/tools-web-search

## التشغيل المجاني (الإعداد الافتراضي الحالي)
- `ZIZO_PROVIDER` الافتراضي `gemini`؛ لا يستدعي OpenAI ولا يتحول إليه عند نفاد الحصة. مفتاح `GEMINI_API_KEY` يضاف كـSecret في Production ثم نشر جديد. اختر مشروع Google Free Tier غير مربوط بالفوترة؛ الكود لا يستطيع منع رسوم حساب Google لو ربط مالكه Billing لاحقاً.
- للأسئلة العامة النموذج الافتراضي `gemini-3.8-flash`، وللبحث بمصادر Google ضمن المجاني `gemini-2.5-flash`. يمكن ضبط `GEMINI_MODEL` و`GEMINI_RESEARCH_MODEL` ضمن القائمة المجانية المسموح بها في `gemini_service.py`.
- الخدمة المجانية لا تستقبل ملفات المكتب أو القضية المختارة. تتطلب `public_query=true` وتستبعد أي سجل لم يوسم سؤالاً عاماً. تمنع معرفات واتصالات ظاهرة وهويات معروفة في سجل الموكلين؛ هذا فحص مساعد وليس ضمان إخفاء هوية. Google تنص على عدم إرسال بيانات شخصية أو سرية للخدمات غير المدفوعة وقد تستخدم المدخلات والمخرجات للتحسين. لا ترسل تفاصيل قضية خاصة حتى بعد حذف الاسم.
- نتائج البحث تعرض المصادر وربط المقاطع، مع اقتراحات Google في iframe معزول بلا سكربتات. لا توجد ادعاءات بحث في الرد عند غياب grounding.
- `/static/legal-tools.html`: ترتيب الوقائع بالتاريخ، مقارنة نسختين بالنص، بناء هيكل مذكرة من بيانات المستخدم، وقائمة مراجعة تنظيمية. تعمل في المتصفح بدون API أو رفع النصوص، مع فتح TXT وتنزيل TXT والطباعة/PDF. لا تولد حكماً قانونياً ولا تحسب المواعيد الإجرائية.
- حصص المزود تتغير حسب المشروع والمنطقة. انتهاء المجاني يظهر رسالة واضحة ولا يشغّل خدمة مدفوعة.
- المراجع: https://ai.google.dev/gemini-api/docs/pricing و https://ai.google.dev/gemini-api/terms .
